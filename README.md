# 오늘 체크 체험판

선생님 PC 화면 한쪽에 오늘 할 학교 업무를 띄워 두고, 다 하면 사라지는 체크리스트예요.
지금은 **초대받은 분만 쓸 수 있는 체험판**입니다. 이 저장소에는 설치 파일만 있어요.

## 설치

1. 오른쪽 **Releases**(또는 [최신 버전](https://github.com/developer-carpet/today-check-releases/releases/latest))에서 `TodayCheck-Setup-버전.exe`를 받아 실행합니다.
2. **"Windows의 PC 보호"** 파란 창이 뜨면 → **추가 정보** → **실행**을 누릅니다.
   (아직 정식 서명이 없는 체험판이라 뜨는 창이에요. 관리자 권한 없이 내 계정에만 설치돼요.)
3. 처음 화면에 받은 **초대 코드**를 붙여 넣고 **시작하기**를 누릅니다. 받은 메시지를 통째로 붙여 넣어도 돼요.

설치 없이 쓰고 싶으면 `TodayCheck-Portable-버전.exe`를 받아 원하는 폴더에서 실행하세요 (자동 업데이트는 설치 버전만).

## 알아 두실 것

- **무료 체험판**이고, 보증은 없어요. 기한은 초대 코드마다 달라요.
- 루틴과 기록은 **이 PC에만** 저장돼요. 앱은 체험판이 열려 있는지 확인하는 파일을 몇 시간마다 읽을 뿐, **아무 정보도 바깥으로 보내지 않아요.** 오류 기록도 PC에만 남고, '문제 보내기'를 누를 때만 복사돼요.
- 체험판을 끝낼 때는 앱 안 안내로 미리 알려 드려요. 끝나도 기록은 지우지 않아요.
- 앱을 복제하거나 뜯어 고쳐 배포하지 말아 주세요.
- 의견은 앱의 **의견 보내기**로 보내 주세요. 정말 고맙습니다!
